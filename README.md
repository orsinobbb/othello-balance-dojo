# 黑白棋平衡道場

純前端黑白棋中後盤教學 MVP。瀏覽器只載入目前需要的精算分片，學生可沿著所有已證明的和局邊前進；必敗落點會留下作為錯誤經驗，但不展開失敗子樹。

## 目前可用範圍

- 16 個 e20 起始盤面，可沿平衡拓樸走到終局和局
- 每個盤面接受所有精確平衡落點，不限制單一標準答案
- 失衡落點不改盤，立即進入重試與複習
- 對手只從精確平衡邊選擇應手，支援 pass 與八種對稱盤面
- SHA-256 分片驗證、Service Worker 離線快取、IndexedDB 本機學習紀錄

示範分片含 20,211 節點、21,235 邊：7,756 條平衡邊、12,995 條失敗邊及 484 條 pass 邊，大小 986,696 bytes。

## 執行與驗證

```powershell
npm.cmd start
npm.cmd test
npm.cmd run audit:data
```

開啟 `http://127.0.0.1:4173/`。不能直接用 `file://`，因為分片載入、Web Crypto 與 Service Worker 需要 HTTP。

## 證據邊界

本版的「精確」只涵蓋內附的 e20→終局 DAG。資料中 `balanced` 表示雙方無失誤仍可和局；`failure` 表示落子後對手已有已證明必勝策略。它不代表 e36→e20 的 AI 候選路徑已被完整證明，也不宣稱涵蓋所有 8×8 黑白棋盤況。

目前發布的是可獨立執行的垂直切片；後續資料版本會沿用相同 manifest、分片驗證與證據邊界。
