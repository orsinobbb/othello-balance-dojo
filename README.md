# 黑白棋平衡道場

純前端黑白棋逐手教學。黑方與白方都由使用者操作；每一步不是只顯示答案，而是依序學習：

1. 讀空格連通區，不被目前棋子數誤導。
2. 比較翻子數與落子後的對手行動力，縮小候選。
3. 找孤立單格、雙方共用的節奏格，以及開角代價。
4. 顯示所有合法手的完整搜尋結果，證明哪些路線能維持和局。

選錯時保留盤面並說明為何必敗，使用者可重試；選對後換另一方繼續逐手學習，直到終局。

題目採循序解鎖：預設從第 001 題開始，完成終局和局後以穩定盤面 ID 寫入 `localStorage`，記錄成功時間、完成次數與步數，再解鎖下一題。擴增或重排題庫不會讓既有進度錯位。

## 資料範圍

- 100 個 e20 教學起始盤面
- 113,902 個盤面節點、118,883 條關係
- 42,421 條平衡關係、74,111 條失敗關係、2,351 條 pass 關係
- 7 個二進位分片，共 5.29 MiB；每片載入時驗證 SHA-256
- 目前資料保存的是「可維持和局／無失誤下必敗」類別，沒有虛構未保存的最終子差

## 載入策略

啟動時只下載約 33 KiB 的題目目錄，再依目前題目載入所屬分片（約 0.5–1.0 MiB）。同一分片的 16 題共用資料且只載入一次；Service Worker 會把使用過的分片留作離線練習，不會在首次開站預載全部 5.29 MiB。

重新產生 100 題版本：

```powershell
npm.cmd run build:release100
```

## 本機驗證

```powershell
npm.cmd start
npm.cmd test
npm.cmd run audit:data
```

開啟 `http://127.0.0.1:4173/`。請使用 HTTP，不要直接用 `file://`，因為資料驗證與 Service Worker 需要瀏覽器安全環境。

## 架構

頁面只載入靜態 HTML、CSS、JavaScript 與預先精算的 DAG 資料，不需要後端或執行中的求解器。Service Worker 提供離線快取，IndexedDB 保存已驗證資料。
